# Glosario

[Inicio](../README.md)

| Término | Significado en el curso |
|---|---|
| Tipo abstracto de datos | Contrato de operaciones y resultados, independiente de representación |
| Invariante | Propiedad conservada entre operaciones públicas |
| Altura AVL | Vacío=0, hoja=1 |
| Factor AVL | Altura izquierda menos altura derecha |
| Rotación | Cambio local de enlaces que conserva el inorden |
| Montículo | Árbol completo con prioridad padre–hijos |
| Cola de prioridad | Tipo abstracto que retira según un comparador |
| Grado mínimo t | Convención B: t-1 a 2t-1 claves en nodos no raíz |
| Separador B+ | Mínimo del hijo a su derecha en esta variante |
| Colisión | Claves diferentes que comparten posición hash inicial |
| Tumba | Estado de una celda eliminada que no interrumpe sondeo |
| Amortizado | Costo promedio por operación en una secuencia, sin suponer aleatoriedad |
| Esperado | Costo bajo supuestos de distribución o aleatoriedad |
| Relajación | Sustituir una distancia por un candidato estrictamente menor |
| INF | Centinela de ausencia de ruta conocida, no costo real |
| DSU | Partición con unión y consulta de representante |
| MST | Árbol de expansión con menor suma total de aristas |
| Bosque mínimo | Un árbol mínimo por componente |
| Ciclo negativo | Ciclo cuya suma permite reducir costos sin límite al repetirlo |
| Sigmoide | Activación 1/(1+exp(-z)) |
| Inferencia | Calcular salidas con parámetros existentes |
| Entrenamiento | Modificar parámetros utilizando datos y un procedimiento definido |
| Fuga de información | Usar al ajustar información que no debería estar disponible para evaluar |
| SIG | Sistema de información geográfica |
| Topología de red | Conectividad que define qué recorridos son válidos |
| GeoJSON | Formato JSON de geometrías y features geográficas |
| Flujo | Procesamiento incremental de registros |
| Partición | División de datos o trabajo según un criterio |
| Máquina de estados | Control que decide según estado actual y entrada |
